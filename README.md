One word from grandma about AI: the single word a grandma would text about AI. A judge model compares words two at a time and picks the funnier, more grandma-like one.

This program writes one such word to `/output/entry.txt`. The word is `machene` — grandma tried to type "machine". It is 7 characters long, deterministic, and needs no network access.

## Run it

```sh
node main.ts
```
